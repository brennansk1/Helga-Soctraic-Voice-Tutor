# Sprint: everything seven audits found

Seven independent reviews ran against the live system on 2026-08-25 — content,
data loss, the tutoring contract, launch readiness, storage/hardware, the
research service, and brand/visual. This is every finding, ordered by what it
costs the learner, with what is already done marked.

The goal it serves: **a learner uses the SQL and Advanced SQL courses tomorrow,
in Mode A, without hitting anything that stops them or being told something
false** (`docs/READY_FOR_USE.md`).

---

## Already fixed this session

Recorded so the sprint is not re-litigated, and because several of these were
found only because an earlier fix exposed them.

**Research grounding** — web search was returning nothing at all (`yep`/`mojeek`
inherited `disabled: true` from SearXNG defaults; `marginalia` did not exist in
the image) · domain routing matched `art` inside `partitioning` and `war` inside
`warehouse` · relevance was judged without the subject · `[a-z]{4,}` discarded
`sql` from every query · no deadline on a call that ran 280s · a rate-limited
host consumed the whole budget · `had_error` at the wrong indentation meant no
empty lookup was ever cached (~475 arXiv round trips per build) · Crossref's
`select` omitted `abstract`, so it returned nothing, ever · a throttle log
printed 52740s and slept 10.

**Storage and data safety** — a failed statement held the write lock forever
(104 unprotected writes) · the self-heal I added then rolled back writes that
were about to commit · concept `.md` written non-atomically from a thread pool ·
`update_course`'s SQLite half swallowed failures while its docstring claimed
otherwise · a stale build reverted learner-owned fields · `create_course` left
no timestamp to compare against · the 4h build backstop was shorter than a
documented 5.5h build.

**Pipeline correctness** — hydration re-derived mastery, domain and the brief
that the course already recorded · the depth contract demanded a named theorem
of every SQL concept (0 of 16 known-good concepts had one) · the word cap
counted the citation list · the generator was never asked for the definition it
was judged on (8 of 8 first-pass misses) · content guards now reject model
deliberation, boilerplate sections and build apologies at the write path.

**Surface** — the dashboard read `total_courses` while the API returned
`courses`, so it showed 0 next to "You have 4 courses" · course cards printed
raw enum values · titles were lowercased by the command parser · the research
`/health` returned a 500 HTML page · the wordmark was underlined on every page ·
the mode badge printed escaped HTML on the signature screen · the mobile header
overflowed to 465px in a 375px viewport, putting the hamburger and theme toggle
off-screen · the Memory Palace button rendered as an empty capsule · course
buttons wrapped mid-label.
