How to Use This Session

Modes: Helga operates in different modes. The UI will change automatically based on the current mode.

  • Mode 1 (Socratic Learning): Engages you in a question-and-answer dialogue. The left-hand panel shows your course progress. You can click on topics to navigate.
  • Mode 2 (Spaced Repetition): Review mode with flashcards. Answer questions to reinforce memory.
  • Mode 3 (Memory Palace): Spatial visualization for placing and recalling concepts in a 2D map.
  • Lobby: The default state. From here, you can start or create courses.

Commands:

  • start course [topic] - Begins a lesson on a specific topic.
  • create course [topic] - Researches and creates a new course. This may take several minutes.
  • exit or quit - Returns you to the Lobby from a course.
